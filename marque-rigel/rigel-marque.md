# Rigel, une marque Orion

## Nom
**Rigel** est l'étoile la plus brillante de la constellation d'Orion. Son nom vient de l'arabe « rijl », le pied du chasseur.

- La filiation se lit sans explication : Orion est la constellation, Rigel son étoile.
- Cinq lettres, identique en français, en anglais et en arabe.
- Le nom ne nomme aucun métier, donc il couvre tous les agents IA que vous lancerez.

## Signature
- Sous le logo : « Agents IA · Une marque Orion »
- Slogan : « Vos agents IA, *en orbite.* »

## Logo
Orion a pour symbole un anneau, une planète et une étoile. Rigel reprend les trois et inverse les rôles : l'étoile devient le sujet, tenue par une orbite qui passe derrière puis devant elle, avec une planète en couleur nova.

| Fichier | Usage |
|---|---|
| `logo-tuile.png` | Logo complet sur tuile sombre, comme celui d'Orion |
| `logo-nuit.png` | Version horizontale, thème Nuit |
| `logo-jour.png` | Version horizontale, thème Jour (devis, documents) |
| `icone.png` | Photo de profil, favicon |
| `planche-de-marque.png` | Vue d'ensemble |
| fichiers `.svg` | Versions vectorielles, texte converti en tracés |

## Ce qui vient du système Orion
- Couleurs : `jet-black` #05030a, `electric-indigo` #6d3bff, `hyacinth-blue` #8a63ff, `lavender-blue` #c6b0ff, `nova` #ffb547.
- L'orbite utilise le dégradé `gradient-orbit` ; le fond utilise `gradient-halo`.
- Polices : Poppins SemiBold pour le mot-symbole, Poppins Medium en capitales espacées pour la signature, Instrument Serif italique pour le mot d'accent.
- `nova` n'apparaît qu'une fois, sur la planète.

## Points non vérifiés
- Je n'ai pas pu ouvrir le fichier du logo Orion ni ses motifs : l'étoile et l'orbite sont redessinées d'après la description du système, pas copiées. À comparer avec le logo réel.
- Le nom : d'autres sociétés s'appellent Rigel dans d'autres secteurs. À contrôler au registre du commerce, à l'INAPI, pour les domaines et les comptes sociaux.
