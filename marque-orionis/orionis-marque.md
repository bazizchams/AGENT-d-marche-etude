# Orionis, par Orion

## Nom
**Orionis** veut dire « d'Orion » en latin. C'est le mot que les astronomes ajoutent au nom de chaque étoile de la constellation (Alpha Orionis, Beta Orionis).

- Le nom contient Orion en entier : la filiation se voit à la lecture.
- Il dit littéralement « qui appartient à Orion », ce qu'est une filiale.
- Il se prononce de la même façon en français, en anglais et en arabe.

## Signature
- Sous le logo : « Agents IA · Par Orion »
- Slogan : « Vos agents IA *ne dorment jamais.* »

## Logo
La Ceinture d'Orion : les trois étoiles alignées qui font reconnaître la constellation. Elles sont reliées comme sur une carte du ciel et grandissent de gauche à droite, pour la progression de l'entreprise cliente.

| Fichier | Usage |
|---|---|
| `logo-tuile.png` | Logo complet sur tuile sombre |
| `logo-nuit.png` | Version horizontale sur fond sombre |
| `logo-jour.png` | Version horizontale sur fond clair (devis, documents) |
| `icone.png` | Photo de profil, favicon |
| `planche-de-marque.png` | Vue d'ensemble |
| fichiers `.svg` | Versions vectorielles, texte converti en tracés |

## Univers : l'aurore boréale
Orion est une nuit violette traversée d'orbites. Orionis est la lumière verte qui parcourt le ciel pendant que tout le monde dort.

| Couleur | Code | Rôle |
|---|---|---|
| Abysse | `#03110f` | Fond principal |
| Boréal | `#0fb89a` | Aplats, départ du dégradé |
| Aurore | `#2bf5a8` | Couleur signature, texte d'accent sur fond sombre |
| Glacier | `#b8ffe6` | Lueurs, fin du dégradé |
| Rose polaire | `#ff5fa2` | Accent rare : un prix, un badge, un mot |
| Brume | `#f2fbf7` | Fond clair |
| Sapin | `#0a6b5a` | Texte d'accent sur fond clair |

## Polices
- Sora SemiBold pour le nom et les titres, Sora Regular pour le texte (Google Fonts, gratuite).
- Instrument Serif italique pour un mot d'accent : c'est le seul élément repris d'Orion, pour garder un air de famille.
